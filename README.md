# Prompt Engineering 

This repository contains the **modules, practical exercises, and programs** completed as part of the **Prompt Engineering Lab** and also it includes different prompt engineering techniques and practical examples.

* Prompt Engineering is the process of creating effective instructions (prompts) to get better and more useful responses from **Generative AI and Large Language Models (LLMs)**.

## 🛠️ Tools Used

* Python
* Jupyter Notebook
* Google Colab
* Generative AI / LLMs
* LangChain

## 🎯 Objective

The main objective of this lab is to learn how to **design effective prompts and use Generative AI tools efficiently**.
